# Pasta /img

Substitua os placeholders SVG por imagens reais.

| Arquivo | Uso | Tamanho recomendado |
|---|---|---|
| `img.png` | Hero — desktop | 1200×1500 (4:5) |
| `imgmb.png` | Hero — mobile | 800×1000 (4:5) |
| `dra.png` | Retrato (Sobre) | 1200×1500 (4:5) |
| `ba-face-before.jpg` / `ba-face-after.jpg` | Antes/Depois — Full Face | 1000×1250 |
| `ba-lips-before.jpg` / `ba-lips-after.jpg` | Antes/Depois — Lábios | 1000×1250 |
| `ba-glut-before.jpg` / `ba-glut-after.jpg` | Antes/Depois — Glúteo | 1000×1250 |
| `clinic-recepcao.jpg` | Mosaico — Recepção | 1200×800 |
| `clinic-sala01.jpg` | Mosaico — Sala 01 | 800×600 |
| `clinic-mimos.jpg` | Mosaico — Cardápio | 800×600 |
| `clinic-lounge.jpg` | Mosaico — Lounge | 800×600 |
| `clinic-corporal.jpg` | Mosaico — Sala corporal | 800×600 |

Após adicionar, substituir os blocos `<div class="photo-ph">…</div>`
no `index.html` por `<img src="img/arquivo.jpg" alt="..." loading="lazy">`.
